### 1. What is API authentication?
API authentication verifies the identity of a client using tokens, API keys, or credentials.

---

### 2. What is broken authorization?
When users can access resources they should not be allowed to access.

---

### 3. Why is rate limiting important?
Prevents abuse, brute-force attacks, and denial-of-service attempts.

---

### 4. Difference between GET and POST?
GET retrieves data.
POST sends data to the server.

---

### 5. Common API security risks
- Broken authentication
- Broken authorization
- Injection
- Rate limiting issues
- Misconfiguration
