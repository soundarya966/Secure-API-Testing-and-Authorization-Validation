# Secure API Testing & Authorization Validation

This project demonstrates testing REST APIs for common security
misconfigurations including authentication validation, authorization flaws,
input validation issues, and missing rate limiting.

---

- Postman
- cURL
- Public test API (JSONPlaceholder)

## OWASP API Risks Covered
- API1: Broken Object Level Authorization
- API2: Broken Authentication
- API4: Lack of Resources & Rate Limiting
- API8: Injection / Input Validation
